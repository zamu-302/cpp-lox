The problem with this tho is that we have an abstract expression and we have different types that inherit from it and all those have different operations and to resolve that in runtime(dynamic polymorphism). and there is a big design issue with dynamic polymorphism you can't easily resolve type and operations at the same time so you have to choose between having a specific number of types or operations and make the code maintainable. And based on this approach having specific number of types was choosen thus the design is Visitor pattern.
